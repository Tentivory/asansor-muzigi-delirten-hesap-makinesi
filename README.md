# 🚡 Asansör Müziği Delirten Hesap Makinesi

## Bu Ne?

Dünyanın **en ciddi** ve aynı zamanda **en saçma** hesap makinesi. Normal hesap makineleri sizi sıkar. Bu ise asansör müziği çalar gibi yapar, sizi bekletir, komşu teyzelerin dedikodularını fısıldar ve sonunda (belki) doğru sonucu verir.

### Özellikler (Abartılı Liste)
- ✅ Gerçekten toplama yapar (inanılmaz!)
- ✅ Asansör müziği simülasyonu (la la laaaa)
- ✅ Rastgele komşu teyze yorumları
- ✅ Sonsuz bekleme hissi (gerçekçi asansör deneyimi)
- ✅ Delirme garantili (para iadesi yok)
- ❌ Çıkarma, çarpma, bölme (asansör mühendisleri henüz hazır değil)
- ❌ Gerçek müzik (ama hayal edin yeter)

## Nasıl Kullanılır?

```bash
python hesap_makinesi.py
```

Sonra iki sayı girin. Bekleyin. Delirin. Tekrar deneyin.

## Teknik Detaylar

Bu proje, modern yazılım mühendisliğinin zirvesidir. Kullanılan teknolojiler:
- Python 3.x (asansör dilinde 'yılan')
- time.sleep() (gerçek zamanlı bekleme simülasyonu)
- random (kaos teorisi)

## Katkıda Bulunma

Lütfen katkıda bulunmayın. Bu proje zaten mükemmel. Eğer isterseniz, asansör müziği için daha fazla 'la la la' ekleyebilirsiniz.
